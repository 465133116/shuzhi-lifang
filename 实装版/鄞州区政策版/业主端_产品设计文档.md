# 数治理方 · 业主端 产品设计文档

*文档版本：V2.0 | 编制日期：2026年7月 | 适用系统：数治理方社区治理平台*
*政策依据：鄞社发〔2026〕6号 · 鄞州区社区治理数字化建设实施意见*
*品牌："如我在居·共享家"*

---

## 一、端口概述与定位

### 1.1 端口定义

业主端是数治理方四端生态中的**服务消费端与治理参与端**，以"如我在居·共享家"为品牌理念。业主在此办理个人事务、参与社区治理、接收各端推送信息，是工单闭环的起点与终点。

- **接入形态**：微信小程序
- **核心定位**：需求发起端 + 结果验收端——工单闭环的起点和终点
- **品牌理念**：如我在居·共享家——让每一位业主真正成为社区的主人

### 1.2 生态位置

业主端在四端生态中处于"需求发起端"和"结果验收端"的双重位置：

| 维度 | 说明 |
|------|------|
| 向上 | 向物业端发起服务需求、向业委会端参与治理决策、向社区端接收政策与服务 |
| 向下 | 验收各端的处理结果、评价服务质量、参与社区治理闭环 |


### 1.5 端口关系矩阵

| 功能 | 业主端 | 物业端 | 业委会端 | 社区端 |
|------|:--:|:--:|:--:|:--:|
| 诉求上报 | 提交方 | 接收处理 | 接收处理 | 接收处理 |
| 矛盾调解 | 申请方 | 涉事方 | 涉事方 | 调处方 |
| 线上议事 | 参与+投票 | — | 发起+管理 | 监督 |
| 党员报到 | 报到+认领 | — | 管理方 | 统筹管理 |
| 志愿服务 | 参与+微心愿 | — | — | 发布+管理 |
| 考评 | 评价方 | 被考评 | 被考评 | 数据管理 |
| 积分 | 查询+兑换 | — | — | 规则+管理 |

### 1.3 界面布局

底部四Tab固定导航：

| Tab | 内容 |
|-----|------|
| **首页** | 个人信息区 + 核心功能区 + 社区动态 + 我的工单 |
| **群聊** | 小区总群·楼栋群·兴趣群 |
| **议事** | 业主大会决策·议事厅协商·公示与档案 |
| **我的** | 个人资料·房屋管理·工单中心·积分中心 |

### 1.4 首页布局

业主端打开后默认进入首页，自上而下五大板块：

1. **个人信息区**：定位信息、问候语、天气、头像，下方暂无提醒时显示铃铛图标
2. **服务入口区**：智能报事、建议、投诉三个功能入口
3. **公告栏**：社区动态板块，展示最新公告通知（来源包括物业公告、业委会公示、社区政策下达、不文明行为公示），点击"查看全部"进入详情列表
4. **我的工单**：展示最近工单摘要（类型、状态、提交时间），点击"工单中心"进入完整工单列表
5. **底部导航栏**：四Tab固定导航——首页、群聊、议事、我的

"我的"页面入口说明：
- **社区生活服务**：以入口形式聚合在"我的"页面中
- **党员报到**：位于"我的"页面，在册/在职党员在线报到
- **志愿服务与微心愿**：位于"我的"页面，参与志愿活动、发布或认领微心愿

## 二、角色体系与权限

### 2.1 四级角色

| 角色 | 报修 | 缴费 | 投票 | 申请会议 | 参加议事 | 矛盾调解 | 说明 |
|------|:--:|:--:|:--:|:--:|:--:|:--:|------|
| 访客 | ✗ | ✗ | ✗ | ✗ | 扫码可入 | ✗ | 未登记用户，扫码进入指定会议可参与 |
| 居民 | ✓ | ✓ | ✗ | ✗ | ✓ | ✓ | 已填写小区+房号+手机号 |
| 业主 | ✓ | ✓ | ✓ | ✓ | ✓ | ✓ | AI审核通过的房产证+身份证认证，拥有全部功能 |
| 家属/租户 | ✓ | ✓ | ✗ | ✗ | 按规则 | 部分 | 业主绑定的角色，由业主授权 |

### 2.2 身份升级路径

```
访客 → 填写房号+手机 → 居民 → 上传房产证+身份证 → AI审核 → 业主
```

AI审核不通过时业主可提交异议→AI推送至物业公司人工复核。居民访问业主专属功能时系统提示原因并提供"如何成为业主"引导。

## 三、AI智能管家（高频服务中枢）

### 3.1 定位

AI智能管家是业主端最高频入口，提供7×24小时智能化的私人秘书式服务。支持语音/文字/图片多模态交互，申报维修、投诉建议、矛盾调解、咨询求助均整合于此。

### 3.2 核心能力

| 能力 | 说明 |
|------|------|
| 语音识别 | 长按说话/松手发送，Web Speech API实时转写，zh-CN |
| 意图识别 | 自动识别报修/投诉/咨询/调解类型，生成结构化工单草稿 |
| 智能预填 | AI识别后预填：类型+子类+紧急度+位置→业主确认/修改后提交 |
| 责任分派 | 根据诉求内容自动判定责任主体（物业/业委会/社区），精准分派 |
| 对话式报修 | 多说一句"我要报修"→AI追问"哪个房间？漏水量大吗？"→确认生成工单 |
| 多轮对话 | 支持上下文理解，异常关键词（"经理""投诉"）→自动转人工 |
| 快捷入口 | 对话区上方提供"申报维修""投诉建议""矛盾调解"按钮，一键预填类型 |

### 3.3 与工单中心分工

- **AI智能管家**：侧重"发起+对话式操作"——通过语音、文字、图片快速发起诉求
- **工单中心**：侧重"列表查看、进度追踪"——集中展示我的工单、处理状态、验收与评价

## 四、诉求上报

### 4.1 诉求类型

业主端支持四类诉求工单，覆盖社区治理全场景：

| 类型 | 说明 | 责任主体 |
|------|------|----------|
| 报修 | 家中报修/公共区域报修，需上门处置 | 物业 |
| 投诉 | 服务态度/处理不及时/收费不合理/公区管理/安全隐患等 | 物业→业委会监管 |
| 建议 | 安全管理/环境卫生/设施改善/社区活动/便民服务等 | 物业/业委会 |
| 咨询 | AI先自动回复；AI无法回答→转物业端人工回复（AI回复保留可见） | AI→物业 |

### 4.2 AI智能识别与分派

业主通过AI智能管家以文字/语音/图片描述问题，AI自动完成：

1. **类型判定**：区分报修/投诉/建议/咨询，匹配合适子分类
2. **紧急度判定**：区分紧急（外墙脱落/渗漏/消防）、一般（公区维修）、低优先
3. **责任主体判定**：根据诉求内容自动判定物业责任/业委会责任/社区共治范围
4. **智能预填**：AI预填类型+子类+紧急度+位置+建议责任方→业主确认/修改后提交

### 4.3 家中报修与公区报修

- **家中报修**（室内）：水电故障、门窗损坏、管道堵塞等
- **公区报修**（公共区域）：楼道照明、电梯故障、绿化损坏、外墙脱落等

### 4.4 完整闭环流程

业主提交诉求后，AI智能管家自动识别诉求类型，按责任主体分派至对应端口：

```
提交诉求 → AI识别确认(类型+紧急度+责任主体)
              │
              ├─ 报修 ──────────→ 物业端处理
              ├─ 投诉(物业服务) → 物业端处理
              ├─ 投诉(业委会)   → 业委会端处理（同步至社区端可查）
              ├─ 投诉(公共事务) → 社区端处理
              ├─ 建议(设施/服务)→ 按内容分派对应端口
              └─ 咨询           → AI自动回复 → 无法回答转物业兜底
              │
              └─→ 承接处理 → 反馈完成 → 业主验收 → 评价(感受性+五星)
```

不满意可追加反馈，每个处理方最多3次——超限后自动升级：

| 当前处理方 | 追加上限 | 超限处理 |
|-----------|:--:|-----------|
| 物业 | ≤3次 | 升级至业委会 |
| 业委会 | ≤3次 | 特别标注（社区端可查），不自动升级 |
| 社区/网格员 | ≤3次 | 升级至街道/区级 |

紧急工单超时自动预警推送至对应处理方的上级端口。

### 4.5 AI智能提醒

工单详情页根据《物业服务合同》约定的执行标准自动展示预计完成时间。显示格式："按照《物业服务合同》约定，您的报修工单将在48小时内处理完成"。业委会更新合同后自动同步最新标准。

### 4.6 服务评价与异议

采用双重评价机制：

- **感受性评价**：工单"解决了/没解决"业主的问题——物业履约的底线指标
- **五星评分+可选评论**：服务质量的细化评估

物业对评分有异议时，先向业主端提出解释→业主可修改评分或回复说明→物业仍有异议再提交业委会复核。两档异议机制保障评分公正。

## 五、矛盾调解申请

### 5.1 功能定位

矛盾调解模块是鄞州区"三级调处网络"的线上入口。业主在此提交邻里纠纷、物业矛盾、社区争端等诉求，由系统智能分派至对应调解层级，实现"小事不出网格、大事不出社区、矛盾不上交"。

### 5.2 三级调处网络

| 层级 | 调解主体 | 适用场景 | 响应时限 |
|------|---------|---------|---------|
| **一级·网格调解** | 楼栋长+网格员+物业管家 | 邻里噪音、宠物扰民、楼道占用、轻微纠纷 | 依合同约定响应时限 |
| **二级·社区调解** | 社区调解委员会+业委会 | 物业矛盾、费用争议、公共空间纠纷、中等争端 | 3个工作日内组织 |
| **三级·街道调解** | 街道司法所+社区法律顾问 | 重大矛盾、涉法涉诉、一级二级调解失败升级 | 7个工作日内组织 |

### 5.3 调解申请流程

```
业主提交调解申请 → AI识别矛盾类型与等级 → 系统分派至对应调处层级
→ 调解员受理 → 约定调解时间/方式（线上/线下）→ 开展调解
→ 达成调解协议（线上签署）→ 协议存档 → 业主评价
```

### 5.4 申请要素

- **矛盾类型**：邻里纠纷/物业矛盾/公共空间争议/费用争议/其他
- **涉及方**：可添加邻居房号或选择物业公司
- **事由描述**：文字+图片说明，AI辅助提炼核心争议点
- **期望解决方式**：线上调解/线下调解/均可
- **紧急程度**：一般/紧急（如安全威胁）

### 5.5 调解过程

- **调解室**：线上文字/视频调解室，支持多方同时在线
- **证据上传**：双方可上传照片、文件等证据材料
- **调解记录**：全程自动记录调解对话，生成调解纪要
- **协议签署**：达成一致后线上签署调解协议，具有法律存证效力
- **协议跟踪**：调解协议生效后系统跟踪履行情况，超期未履行自动提醒

### 5.6 升级机制

调解失败或一方不满意时，系统自动逐级升级：
一级调解失败→自动推送至二级社区调解委员会→仍无法解决→推送至三级街道司法所。

## 六、工单中心

### 6.1 工单创建入口

- **AI智能管家**（首页）：语音/文字/图片描述→AI识别→生成工单草稿→业主确认提交
- **快捷入口**：首页"申报维修""投诉建议""矛盾调解"按钮
- **群聊内一键生成**：AI识别群内诉求→生成工单草稿→业主确认

### 6.2 工单列表

集中展示业主提交的所有工单，按时间倒序排列。每条工单显示：编号、类型标签（报修/投诉/建议/咨询/调解）、紧急度标签、当前状态、提交时间、处理方。支持按类型、状态筛选，支持搜索工单编号或关键词。

### 6.3 处理进度查询

工单详情页展示完整生命周期：

- **进度时间轴**：提交→AI识别→分派→接单→处理→完成→验收→评价
- **每个节点**：操作人、操作时间、处理说明
- **超时标记**：红色警告
- **处理结果**：文字+图片详情

### 6.4 工单状态规范（四端统一）

```
待分派 → 已分派 → 处理中 → 待验收 → 已完成
```

任一阶段可变更为"已取消"。已完成可发起不满意追加→待复核。

## 七、通知中心

### 7.1 消息通知

通知中心是业主接收小区各类信息的一站式入口：

- **物业通知**：工单进度、停水停电、设施维护
- **业委会通知**：会议通知、投票通知、公示提醒、考评通知
- **社区通知**：政策下达、制度解读、活动通知
- **AI提醒**：工单超时预警、待办提醒、积分变动

### 7.2 分类筛选

| 标签 | 颜色 | 说明 |
|------|------|------|
| 公告 | 蓝 | 物业/业委会/社区公告 |
| 公示 | 橙 | 业委会公示、财务公开、考评结果 |
| 政策 | 红 | 政策法规、制度文件 |
| 提醒 | 绿 | AI智能提醒、工单通知 |
| 活动 | 紫 | 社区活动、志愿活动、党建活动 |

### 7.3 待办提醒

- 待验收工单提醒（处理完成超过24小时）
- 待投票提醒（会议投票即将截止）
- 待签收提醒（会议资料未签收）
- 待调解提醒（调解约定时间临近）
- 待考评提醒（季度考评窗口开启）

### 7.4 公告与协商结果

#### 公告来源

| 来源 | 内容 |
|------|------|
| 物业公告 | 停水停电通知、设施维护、活动通知 |
| 业委会公示 | 会议决议、财务公示、考评结果 |
| 社区政策下达 | 政策法规、制度解读、通知文件 |

#### 公告轮播

首页顶部公告轮播区展示重要公告（置顶公告自动轮播），点击进入公告详情。置顶公告由物业端/业委会端/社区端设定，每端同时置顶≤3条。

#### 协商结果公示

议事厅协商完成后，协商结果（含各方意见、最终方案、执行计划）自动推送至业主端公示栏。议事厅调解完成后，由调解员选择公示方式——**公开**（推送至公示栏，全体业主可见）、**仅涉事方可见**（仅纠纷各方查阅）、**存档不公开**（仅归档，不对外展示）。公示期内（依合同约定）业主可提出异议，异议进入业委会复议流程。

#### 财务公示

维修金使用完成后自动推送至业主端公示栏。公示内容：申报金额、审批链条、履约评分。

## 八、群聊

### 8.1 群组类型

| 类型 | 说明 | 创建方式 |
|------|------|----------|
| 总群 | 小区全体业主/居民大群 | 系统自动创建，不可退出 |
| 楼栋群 | 同一楼栋业主/居民群 | 系统按楼栋自动归组 |
| 兴趣群 | 业主自发创建（宠物/运动/读书等） | 业主自主创建 |
| 党群群 | 已认证党员自动加入 | 系统自动创建 |

### 8.2 AI智能管家常驻

AI智能管家常驻所有群组，提供群内智能服务：

- 识别群内报修诉求→一键生成工单
- 识别高频话题→推送至自治协作广场
- 识别矛盾苗头→主动建议提交调解申请
- 群公告智能提醒
- 违规内容自动预警

### 8.3 群组创建与管理

业主可自发创建兴趣群：设置群名称、封面、简介、是否公开。公开兴趣群在群聊广场展示，其他业主可申请加入；私密兴趣群通过邀请码加入。总群和楼栋群由系统自动维护，人员随房屋绑定关系自动增删。

### 8.4 自治协作广场入口

总群底部设热门议题入口——将自治协作广场中热度最高的议题以卡片形式展示，打通群聊与议事通道。热度算法：参与人数×2 + 讨论量×1.5 + 点赞数×1。Top3议题卡片展示标题、发起人、参与人数、最新回复摘要，支持一键跳转参与讨论或进入议事厅。

## 九、社区论坛

### 9.1 论坛定位

社区论坛是居民自由讨论的公共空间——区别于议事厅的正式会议机制。论坛承载日常邻里交流、话题讨论、信息分享，是"聊透"的地方（议事厅负责"定下来"）。

### 9.2 话题浏览与发帖

- **话题分类**：邻里互助、社区建议、生活分享、兴趣爱好、寻人找物
- **发帖**：文字+图片，支持话题标签
- **回复**：支持楼中楼回复、点赞
- **热门话题**：按热度排序（参与人数+讨论量），自动推荐。AI持续分析群聊内容，当检测到高频讨论词或争议点时，自动生成论坛话题并打上"AI推荐"标签，推送至论坛热门区

### 9.3 议题转化

论坛话题讨论热度达标后（参与人数≥楼栋/小区业主30%+核心争议点收敛），可被业主代表/意见领袖提炼为正式议题，在议事厅发起表决。论坛负责"聊透"，议事厅负责"定下来"——讨论与决策分离。

## 十、线上议事与投票

### 10.1 议题孵化（三条路径）

- **路径一·业主自主创建**：业主在自治协作广场创建讨论话题→讨论量达标→升级为"热门话题"→业主代表在议事厅发起正式议题
- **路径二·AI群聊挖掘**：AI分析群聊高频词/争议点→生成"AI推荐热门话题"→推送至自治协作广场→充分讨论后进入议事厅
- **路径三·业委会发起**：业委会根据治理需要主动创建话题→推送到自治协作广场供全体讨论

### 10.2 议事申请流程

1. **会议类型选择**：决策会议（集会型，实时在线）或协商会议（慢会型，异步讨论，周期依合同约定）
2. **会议范围选择**：本楼栋或全体业主
3. **AI智能推荐人群**：推荐应邀请的业主代表、意见领袖、利益相关方
4. **核心目的确认**：一句话概括核心目的（≤50字），AI辅助生成摘要
5. **隐私协议签署**：涉及敏感议题需签署线上隐私协议
6. **AI智能审核**：五维度评分（议题明确性/参与范围合理性/时效必要性/流程合规性/历史关联度，各20分，满分100分）。≥70分自动通过，<70分自动拒绝并给出改进建议

### 10.3 议事厅

议事厅是线上会议厅，支持三种会议类型：

- **决策会议**（集会型）：实时在线，所有相关角色到位后开始，适用表决事项
- **协商会议**（慢会型）：异步讨论，周期3-7天，适用意见征集与方案讨论
- **调解会议**：议事厅内置的纠纷调解功能——由调解员（网格员/社区调处员/业委会）发起，邀请纠纷各方进入线上调解室。调解过程全程记录、AI辅助生成调解纪要；达成一致后在线签署调解协议，调解失败则自动升级至上一级调处层级。调解完成后由调解员选择公开方式——公开、仅涉事方可见、存档不公开

#### 会前准备室

会议正式开始前，系统自动创建会前准备室：

- **基础准备**：查看议程、签收资料、签到确认、授权代理、设备检测
- **主持人专用**：发送会议通知、材料备案、表决票准备、合规检查
- **准备进度条**：实时展示完成度，达100%且合规检查通过后方可进入会议

#### AI全流程支撑

- **会前**：AI审核会议申请、提供议题意见
- **会中**：AI三次阶段性小结——第一次重申主题、第二次明确讨论焦点与认同比例、第三次总结
- **会后**：自动生成纪要、表决投票表；第二天通过公示栏向全体业主公示

### 10.4 业主大会与投票

- **投票资格**：仅业主可参与投票表决
- **身份验证**：短信验证码或密码
- **投票选项**：同意/反对/弃权，支持本地哈希存证
- **通过条件**：普通事项——人数和面积均过半数；特殊事项——人数和面积均达2/3以上
- **临时业主大会**：表决参与≥20%业主时自动推送建议至业委会与社区

## 十一、党员报到

### 11.1 功能定位

党员报到模块是鄞州区党建引领社区治理的线上阵地。在册党员和在职党员均可在线报到、认领服务、记录服务时长，将党员先锋模范作用融入社区日常治理。

### 11.2 党员报到流程

```
提交党员身份认证 → AI审核（党员证/组织关系证明）→ 审核通过
→ 获得党员标识（昵称旁显示党徽图标）→ 自动加入党群联络群
```

### 11.3 党员服务认领

| 服务类型 | 示例 | 时长记录 |
|---------|------|---------|
| 政策宣传 | 垃圾分类宣传、反诈宣传 | 计入服务时长 |
| 邻里调解 | 参与矛盾调解、楼栋协商 | 计入服务时长 |
| 志愿服务 | 社区清洁、助老助残、疫情防控 | 计入服务时长 |
| 治理参与 | 议事厅主持、业委会协理 | 计入服务时长 |
| 专业服务 | 法律咨询、医疗咨询、教育辅导 | 计入服务时长 |

### 11.4 党群群聊

系统为每个小区自动创建党群联络群，已认证党员自动加入。群聊列表独立展示，不混入普通群聊。支持党务通知、组织生活线上讨论。

### 11.5 党建活动

党支部可发布党建活动（主题党日、志愿服务、学习教育），党员业主收到活动通知并可在线报名签到，活动记录纳入党员学习档案。

### 12.1 功能定位

志愿服务模块是连接"有能力的人"和"有需要的人"的社区互助平台。业主可报名参加社区组织的志愿活动，也可发布或认领"微心愿"，实现邻里互助的温暖循环。

### 12.2 志愿活动

| 活动日历 | 月视图展示当月志愿活动安排 |

## 十三、业委会与物业线上考评

### 13.1 功能定位

每季度由业主对业委会和物业服务进行线上评议，结果公开透明，作为物业合同续签和业委会履职评价的重要依据。落实鄞州区"业主评议、结果公开、闭环整改"的考评要求。

### 13.2 考评维度

#### 物业服务考评（5维度）

| 维度 | 权重 | 具体评议项 |
|------|:--:|------|
| 服务响应 | 25% | 报修响应速度、处理及时性、工单闭环率 |
| 服务质量 | 25% | 维修质量、保洁效果、安保水平 |
| 服务态度 | 15% | 人员态度、沟通效率、投诉处理 |
| 费用透明 | 20% | 收费合理性、财务公示、公共收益公开 |
| 设施维护 | 15% | 电梯/消防/绿化/公共设施维护状况 |

#### 业委会履职考评（5维度）

| 维度 | 权重 | 具体评议项 |
|------|:--:|------|
| 决策透明 | 25% | 会议公开、决议公示、资金审批透明 |
| 监督力度 | 25% | 物业监管有效性、工单督促率 |
| 财务合规 | 20% | 维修金使用合理性、预算执行率 |
| 沟通协调 | 15% | 业主意见收集、矛盾调解参与度 |
| 制度执行 | 15% | 议事规则执行、业主大会决议落实 |

### 13.3 考评流程

```
考评窗口开放（每季度末考评窗口）→ 业主在线评分（五星+文字意见）
→ 匿名汇总统计 → 结果公示（考评结束后依约公示）
→ 整改反馈（考评对象依约提交整改方案）→ 下季度回头看
```

### 13.4 考评结果

- 结果以雷达图+趋势图展示，支持与上季度、去年同期对比
- 考评结果在业主端公示栏公开发布
- 连续两个季度"不满意"超过30%触发业委会约谈机制
- 考评数据同步至社区端，纳入物业企业信用评价体系

## 十四、居民积分

### 14.1 功能定位

居民积分是激励业主参与社区治理的数字化激励机制。业主参与议事、志愿活动、矛盾调解、建言献策等均可获得积分，积分可兑换社区商户服务，实现"参与有价值、贡献有回馈"的正向循环。

### 14.2 积分获取规则

| 行为 | 积分 | 上限 |
|------|:--:|:--:|
| 参加议事厅会议 | +10/次 | 40/月 |
| 参与业主大会投票 | +5/次 | 20/月 |
| 完成工单验收评价 | +2/次 | 20/月 |
| 提交有效建议（被采纳） | +15/条 | 60/月 |
| 参加志愿活动 | +5/小时 | 80/月 |
| 参与矛盾调解（作为调解员） | +20/次 | 60/月 |
| 认领并完成微心愿 | +10/次 | 40/月 |
| 参与业委会/物业考评 | +5/次 | 20/季 |
| 论坛精华帖 | +10/帖 | 30/月 |
| 党员服务（额外） | +10/小时 | — |

### 14.3 积分兑换

积分可在"积分商城"兑换社区商户提供的服务或商品：

| 兑换品类 | 示例 |
|---------|------|
| 便民服务 | 空调清洗、地暖保养、家政清洁 |
| 生活消费 | 社区超市优惠券、餐饮折扣 |
| 停车优惠 | 临时停车券、月租折扣 |
| 社区活动 | 活动优先报名、专属活动参与权 |
| 荣誉激励 | "社区之星"称号、荣誉证书 |

### 14.4 积分管理

- **积分明细**：每笔积分获取/消费记录，含时间、来源、数量
- **积分排行**：小区积分排行榜（可选匿名），季度/年度积分之星
- **积分有效期**：积分自获取之日起有效期依合同约定，到期前提醒
- **积分转让**：支持积分转赠家人（同一房屋绑定关系）

## 十五、身份认证中心

### 15.1 认证流程

```
上传房产证+身份证照片 → AI OCR识别 → AI审核 → 通过/不通过
```

- **通过**：获得业主身份，解锁全部功能（投票/议事/考评/党员报到）
- **不通过**：业主可点击"提交异议"→AI推送至物业公司→物业人工复核

### 15.2 证件上传

- 支持拍照上传或相册选取
- AI自动OCR识别证件信息（姓名、身份证号、房产证号、房屋地址）
- 系统比对房号与证件信息一致性

### 15.3 异议与人工复核

AI审核不通过时提供三项选择：
1. 重新上传（修正照片质量/信息错误）
2. 提交异议（附说明理由）→推送物业端人工复核

### 15.4 房屋管理

- **多套房产切换**：业主拥有多套房产时可绑定所有房产并一键切换
- **家人/租户绑定**：业主可为家人或租户创建绑定账号并授权
- **授权范围**：查看/代缴费/代报修/代投票（需业主明确授权）

## 十七、与生态其他端口的关系

```

```
