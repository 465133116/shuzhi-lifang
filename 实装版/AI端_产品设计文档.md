# 数治理方 · AI端 产品设计文档

*最后更新：2026-07-28*

## 一、端口概述与定位

AI端是数治理方七端生态中的智能中枢与能力支撑端。它没有独立用户界面——所有能力通过平台API层嵌入各端，在背后做分类、分派、计算、预测、生成。

AI不替代任何一端的主体责任，按"业主→物业→业委会→社区→AI"的数据与流程顺序与各端对接。

## 二、核心能力

### 2.1 工单智能分派
- 业主端提交工单后，AI根据工单类型和内容自动分派至物业/业委会/社区
- 同一工单第3次派往物业时同步推送预警至业委会
- 超时工单仅做标记（添加Warning Tag），不修改工单状态

### 2.2 会议审核
- 业主端提交会议申请后AI自动评分（五维度100分制）
- ≥70分自动通过，<70分自动拒绝

### 2.3 证件OCR
- 营业执照/身份证/房产证等证件智能识别
- AI审核不通过时业主可提交异议→转物业人工复核

### 2.4 合同解析
- 业委会上传物业服务合同后AI解析，提取服务范围/履约时限/违约责任
- 解析结果为物业评分系统提供执行标准
- 未上传合同时AI不执行物业评分

### 2.5 业主大会授权委托书解析
- 识别授权事项与授权维修资金金额（单笔/年度上限）
- 写入规则库约束维修资金审批

### 2.6 重复工单检测
- 同房号同类问题在设定时间窗口内重复提交检测
- 生成预警推送业委会

### 2.7 报修内容识别
- 业主以文字/语音/图片提交报修时AI识别并结构化
- 优先级区分（外墙脱落>渗漏>一般公区维修）

### 2.8 制度条款匹配
- 发起议题/会议/签署文件时自动推送相关法规条文
- 合规扫描与风险提示

## 三、设计原则

| 原则 | 说明 |
|------|------|
| 不替代主体责任 | AI建议仅供参考，最终决定权在业委会/业主大会 |
| 最小必要 | 只处理履职必需的数据，只介入必要流程节点 |
| 可审计 | 所有AI决策可追溯依据（条款、规则、数据来源） |
| 可降级 | AI故障时自动降级，不阻塞业务流程 |

## 四、与各端的关系

| 服务端口 | AI提供的能力 |
|----------|-------------|
| 业主端 | 报修识别·会议审核·证件OCR·重复检测·身份核验 |
| 物业端 | 工单分派·评分计时·重复预警·异常检测 |
| 业委会端 | 合同解析·制度匹配·合规扫描·文书生成·决策建议 |
| 社区端 | 舆情分析·合规扫描·态势报告 |
| 客服端 | 催收时机调度·话术推荐·敏感场景检测 |
