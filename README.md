# 数治理方 · 生态系统

> **社区制度型信用治理系统平台**
> 让每一次服务都有证据、每一次履约都有记录、每一次违约都有后果

---

## 启动方式

双击 `index.html` 即可进入导航页，点击各端口进入。

或用本地服务器（推荐五端联调时使用）：
```bash
npx serve .
# 访问 http://localhost:3000
```

---

## 核心理念

```
收费秩序 = 正当性 × 履约可信度 × 价值感知度 × 守约共识度 × 分类精准度
```

P1让物业能证明自己服务好，P2让该交费的人没理由不交。
