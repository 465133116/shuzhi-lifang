## 指标与阈值

| 指标 | 阈值 | 说明 |
|------|------|------|
| 首次打开弹窗 | ≤ 800ms | 自点击「会议模拟室」至 `#meeting-sim-modal` `display:flex` 且首帧预览可见 |
| 阶段切换 | ≤ 200ms | 自点击 Tab 至 `#meeting-sim-preview` 内容更新且加载层隐藏（本实现模拟延迟 100ms） |

## 推荐测试步骤（DevTools Performance）

1. 打开 `生态/业主端.html`，进入 **议事 → 议事申请**。  
2. 录制 Performance，点击 **会议模拟室**，结束录制，测量 **Event → Paint** 区间。  
3. 再录制一轮：在弹窗内连续切换 **会前 / 会中 / 会后** 各 3 次，统计每次切换耗时取 **P95**。  

## 自动化辅助

可在 `生态/tests/meeting-sim-room.test.html` 中查看基于 `performance.now()` 的粗略探针（iframe 同源时启用）。

## 本实现的前端策略（与性能相关）

- 预览为字符串模板拼接，无远程请求。  
- 切换使用短延迟（100ms）展示加载态，避免与 200ms SLA 冲突。  
- 动画使用 CSS `transform` / `opacity`，降低合成层开销。
