# 意向池规则 · 定稿 v1.3

> 2026-08-14 · 两轮评审 + 分配机制定稿（B方案） · 开发以此为准
> 关联文档：催收端_分配逻辑_最终.xlsx / 客服培训_分配流转功能.html / 意向池功能_思维导图.html

## 一、计数

- 上限 **50 户**，只数三态：**催收中 / 暂停 / 部分还款**
- **满额拉新**：系统提醒客服已满，由**客服自行选择**剔除一户回主池（系统不自动剔除）
- 其他状态一律不占名额
- **上限50户即全部口径——没有"保留名额"这个说法，不与任何保留额度联动**
- 界面显示两行：`计入名额 X/50` + `回款取消待跟进 N户`（分开显示）
- 池内列表排序：**按欠费金额大小**（大额在前）

## 二、拉入

- **无门槛**：任何接通户均可拉入（含 E/F）
- 时机：**挂断后**的分流弹窗操作（通话中不弹）
- 动作：**移入**——从个人池移入意向池，唯一归属（非复制）
- **AI外呼接通的户也可拉入**（拉入后归该客服名下）
- 拉入后**全局锁定**：该户不参与任何流转分配（主池/流动池/补位全部跳过）
- 拨打节奏：客服自行安排

## 三、在池状态

| 状态 | 计数 | 说明 |
|------|:--:|------|
| 催收中 | ✅ | 正常跟进 |
| 暂停 | ✅ | **管理员触发**（争议处理/业主要求缓联/投诉），期间不拨打；**恢复由客服跟进**；客服可手动移出暂停户 |
| 部分还款 | ✅ | **还1分钱也算**；回款数据**经工作群沟通确认**；剩余金额继续跟 |
| 回款取消 | ❌ | **管理员标记**放回，**放回时标签不变**（后续通话照常更新），理论上可超50 |
| 其他 | ❌ | 一律不占名额 |

- 池内户后续被判 E/F：**继续预留**，不自动移出

## 四、移出

| 场景 | 去向 |
|------|------|
| 回款（**以物业公司报回款为准**） | 自动移出 |
| 剩余减免结清 | 算回款，自动移出 |
| 回款又取消 | 放回意向池，不计上限 |
| 客服手动移出（判断无望） | **回流动池，下次流转给其他人** |
| 满50拉新被踢 | **正常回流动池**（只踢计入名额的） |
| 业主声称已缴 | **先放入意向池等物业确认**，确认期间客服自定是否联系 |

## 五、归属与边界

- 周三轮换不回收，跟人走
- 不算在个人池 250 内
- 前期无自动移出
- 客服离职：**管理员回收后分派给指定客服**
- 项目结案：该小区意向户**自动终止**
- 投诉缓联：**仅物业通知或管理员操作暂停**
- 管理员权限：目前**仅查看**（含已定的暂停触发、回款取消标记、离职回收操作）
- 考核：**暂不设**意向池考核指标

## 六、与分配的关系（B方案 · 2026-08-14 拍板）

- **意向池 = 客服留住业主的唯一通道**：已废除"接通正标签自动保留"机制。接通的号不拉入意向池，下次轮换回收流转给别人
- 每周1250 = 主池新户补位（未触达优先·金额排序·轮流分5人各250）
- 个人池250户每次轮换全量回收；意向池户全局锁定，不参与任何流转分配
- 四周覆盖：W1 25% → W2 50% → W3 75% → W4 100%；第5轮起复打未接通 + 新导入户补位
