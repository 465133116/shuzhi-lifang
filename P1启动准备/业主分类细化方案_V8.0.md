# 业主画像分类细化方案 V8.0

> **基于：** 业主画像V7.0 + 业主分类V4.0 + P1_楼栋破冰参考逻辑
> **编制：** 2026-06-30
> **核心改进：** 从"6类粗分"升级为"6类×细分+交叉模式+响应级别"三维分类体系

---

## 一、当前分类体系的不足

| # | 问题 | 影响 |
|---|------|------|
| 1 | **C类太粗**：从众/拖延/不满/遗忘混在一起，但破冰策略完全不同 | 客服不知道该用什么话术开场 |
| 2 | **D类无细分**：1次失约和5次失约都是D，严重程度无法区分 | 优先级排序不精确 |
| 3 | **E类无细分**：拒接/攻击/拒缴混在一起，处置策略不同 | 对拒接型持续拨号浪费资源 |
| 4 | **信号只有二值**：报修1次和8次都是A=on，紧急度丢失 | 列表排序只看优先级分，分类本身不体现轻重 |
| 5 | **交叉模式缺失**：A+B和A+D处理方式不同，但系统不提示 | 客服需自行判断 |
| 6 | **时间颗粒度不够**：只有30天一个阈值 | 7天内的恶化、14天的趋势变化被忽略 |
| 7 | **沟通偏好未接入分类**：personalityType数据有但不参与分类 | 话术推荐与分类脱节 |
| 8 | **无"首次响应"概念**：新产生信号的业主和长期信号的业主同等对待 | 无法识别"刚出问题急需响应"的业主 |

---

## 二、细化方案总览

```
业主分类 = 主分类(1个·含细分子类型) 
         + 辅助信号(0~N个·含强度等级) 
         + 交叉模式(0~1个·预设组合) 
         + 响应级别(1个·决定拨打紧急性)
```

### 2.1 六类细分总表

| 主类 | 现有子类型 | V8.0 新增子类型 | 细分维度 |
|:--:|------|------|------|
| **A** | 报修型/投诉型/混合型/反复型 | A·高优先级型(频次驱动) | 工单数≥3 → 自动标记 |
| **B** | B1自述/B2反复/B3可验证 | B·临时困难 / B·长期困难 | 首次困难 vs 历史困难 |
| **C** | 未触达/已解决/沉睡 | **C1~C6 六类细分** | 按心理动机拆分 |
| **D** | — | **D1~D4 四级惯性** | 按失约次数+态度 |
| **E** | — | **E1~E4 四型对抗** | 按对抗方式拆分 |
| **F** | 号码无效/未覆盖/lb关键词 | F·产权变更 / F·继承纠纷 | lb关键词细分 |

### 2.2 响应级别（新增）

不论分类，每个业主额外挂一个响应级别，控制拨打节奏：

| 级别 | 条件 | 动作 |
|:--:|------|------|
| **R0·紧急** | A类+未闭环≥3 或 E类新触发(<7天) | 24h内必须联系 |
| **R1·优先** | 主分类得分≥70 或 交叉模式=恶化中 | 48h内联系 |
| **R2·常规** | 普通活跃信号 | 本周内联系 |
| **R3·观察** | C类或得分<40 | 可排后，批量短信触达 |
| **R4·静默** | C·沉睡>60天 或 F类 | 不主动外呼 |

## 三、C类六分法（核心细化）

### 3.1 问题根源

当前C类包含了从众、拖延、不满、遗忘、信息不足五种完全不同心理的业主。客服面对C类业主时无法针对性破冰。

### 3.2 细分方案

| 子类型 | 含义 | 触发条件 | 破冰策略 | 信号来源 |
|:--:|------|------|------|------|
| **C1·从众观望** | 等待社会证明 | 通话含"别人交我就交""大家都交了吗"等从众关键词 | L1缴费事实破冰 → 本楼栋缴费率+邻居案例 | 语音检测/通话记录nt |
| **C2·拖延观望** | 无紧迫感 | 通话含"不急""再看吧""到时候再说" | 工单闭环+满意度+服务改善案例 | 语音检测/通话记录nt |
| **C3·对比观望** | 觉得本小区不如别的小区 | 通话含"隔壁小区""人家那边""凭什么" | 本小区vs对比数据+进步趋势 | 语音检测/通话记录nt |
| **C4·信任缺失** | 不满但没到A类程度 | 历史满意度<3星 或 通话含"物业不管""服务差"但未提交正式投诉 | 先处理情绪，展示近期改进数据 | 工单+通话记录 |
| **C5·已解决** | A消除后的过渡态 | A类工单闭环≥3星，无其他信号 | 回顾正面体验，试探缴费意向 | 自动判定 |
| **C6·信息不足** | 纯默认，真的不知道 | 无工单+无通话+无标签+无任何信号 | 首次破冰外呼，了解情况 | 兜底默认 |

### 3.3 C类判定流水线

```
IF 有A消除记录 AND 无其他信号 → C5·已解决
ELSE IF 通话含从众关键词 → C1·从众观望
ELSE IF 通话含拖延关键词 → C2·拖延观望
ELSE IF 通话含对比关键词 → C3·对比观望
ELSE IF (满意度<3星 OR 通话含不满关键词) AND 无正式投诉工单 → C4·信任缺失
ELSE IF 无任何信号 → C6·信息不足
```

### 3.4 C类破冰策略对照

| 子类型 | 第一句话 | 核心数据 | 禁忌 |
|:--:|------|------|------|
| C1·从众 | "你们楼栋XX户已经交了" | 楼栋缴费率+邻居案例 | 不要说教 |
| C2·拖延 | "最近小区处理了不少问题" | 工单闭环+满意度 | 不要催 |
| C3·对比 | "我们小区最近有这些进步" | 本小区趋势数据 | 不要辩解 |
| C4·信任缺失 | "之前可能有不到位的地方" | 近期改进数据+具体案例 | 不要推卸 |
| C5·已解决 | "上次修的水管现在没问题了吧" | 历史工单记录 | 不要直接要钱 |
| C6·信息不足 | "有什么需要帮忙的吗" | — | 不要预设立场 |

## 四、D类四级惯性

### 4.1 细分方案

| 子类型 | 条件 | 含义 | 客服策略 |
|:--:|------|------|------|
| **D1·轻度惯性** | 无争议承诺 1~2次 | 刚出现失约苗头 | 温和提醒+设置明确时间节点 |
| **D2·中度惯性** | 无争议承诺 3~4次 | 已形成模式 | 留痕+短信确认+约束升级 |
| **D3·重度惯性** | 无争议承诺 ≥5次 | 惯犯 | 发正式函件+业委会抄送 |
| **D4·沉默型** | 承诺后≥14天不接电话 | 失联回避 | 短信+上门+标记风险 |

### 4.2 判定

```
D计数 = 无争议承诺次数（经过7天衰减后的有效计数）

D计数 1-2 → D1·轻度惯性
D计数 3-4 → D2·中度惯性
D计数 ≥5  → D3·重度惯性

IF D≥D2 AND 最近14天拒接≥2次 → 升级为D4·沉默型（辅助标记，主分类仍按计数）
```

### 4.3 D类衰减细化

| 条件 | 动作 |
|------|------|
| 自上次无争议承诺起，每7天无新承诺 | D有效计数 -1（衰减，非消除） |
| 业主登录小程序 | D立即降一级 |
| 业主创建工单 | D转为辅助，主分类变A |
| 业主缴费（P2接入后） | D直接消除 |

## 五、E类四型对抗

### 5.1 细分方案

| 子类型 | 触发条件 | 含义 | 客服策略 |
|:--:|------|------|------|
| **E1·拒接型** | 拒接≥3次，无攻击/拒缴 | 可能是不好意思、不想沟通 | 换时段/换号码/短信触达。不持续拨号。 |
| **E2·攻击型** | 含攻击性投诉（辱骂/威胁/群内攻击） | 情绪对抗，可能扩散影响他人 | 升级主管+法律留痕。不正面冲突。 |
| **E3·拒缴型** | 通话明确说"不交""死也不交" | 原则性拒缴 | 了解原因→归入争议或法律途径。不硬催。 |
| **E4·差评累积型** | 态度差评≥3次，但无拒接/攻击/拒缴 | 对服务不满累积 | 先解决服务问题，再谈其他。避免再刺激。 |

### 5.2 E类处置对照

| 子类型 | 拨打策略 | 话术方向 | 升级条件 |
|:--:|------|------|------|
| E1·拒接型 | 间隔≥3天拨打，≤3次/月 | 短信为主，给台阶下 | 连续2月拒接→标记静默 |
| E2·攻击型 | 不主动拨打，被动接听 | 冷静、不辩解、记录 | 扩散到群→业委会介入 |
| E3·拒缴型 | ≤1次/月确认态度 | 了解原因，记录证据 | 启动法律评估 |
| E4·差评累积型 | 用服务切入，不提争议 | 先解决问题 | 连续3次服务闭环好评→降级 |

### 5.3 E类降级路径细化

| 路径 | 条件 | 降到哪里 |
|------|------|------|
| 时间 | 连续60天无新攻击+拒接<3 | C5·已解决 |
| 行为·接通 | 接通后态度明确软化 | A（如有工单）或 C5 |
| 行为·工单 | 提交非攻击性报修 | A·报修型（E转辅助） |
| 行为·登录 | 登录小程序 | E维持但拒接计数-1 |
| 客服手动 | 通话后判断态度软化 | 手动覆盖 |

## 六、A类细分子类型增强

### 6.1 现有子类型保留 + 新增

| 子类型 | 条件 | 说明 |
|:--:|------|------|
| A·报修型 | 报修≥1, 投诉=0 | 保留 |
| A·投诉型 | 投诉≥1, 报修=0 | 保留 |
| A·混合型 | 报修≥1, 投诉≥1 | 保留 |
| A·反复型 | 同问题≥3次 | 保留 |
| **A·高优先级型** | 未闭环工单≥3 或 超SLA≥7天 | **新增**：频次/时效驱动的紧急标记 |
| **A·首次型** | 第一次产生A信号 | **新增**：区分"刚出问题"和"老问题" |

### 6.2 A·首次型的价值

- 首次A=刚出问题→响应窗口黄金期，24h内响应可大幅提升满意度
- 非首次A=老业主→已有历史画像，可按常规节奏处理

## 八、交叉模式（预设组合）

当一个业主同时存在多类显著信号时，系统自动识别预设组合并给出组合策略：

| 交叉模式 | 信号组合 | 含义 | 组合策略 |
|:--:|------|------|------|
| **争议+困难** | 主A + 辅B(得分≥40) | 有具体问题且经济困难 | 先解决问题→再协商缴费 |
| **争议+惯性** | 主A + 辅D(得分≥50) | 可能用报修当拖延借口 | 解决问题+留痕+设置明确期限 |
| **对抗+困难** | 主E + 辅B(得分≥40) | 对抗但确实困难 | 先降对抗→再协商。不硬催 |
| **对抗+惯性** | 主E + 辅D(得分≥50) | 最难处理组合 | 升级主管+法律评估 |
| **困难+惯性** | 主B + 辅D(得分≥50) | 困难且失约 | 协商分期+留痕约束 |
| **恶化中** | 近7天分类向差迁移(如C→A, C→E, A→E) | 正在变差 | 24h内响应+重点跟进 |
| **好转中** | 近7天分类向好迁移(如E→A, A→C, D→C) | 正在改善 | 趁热打铁+正面强化 |
| **首次信号** | 任何类别首次触发 | 新出现的行为信号 | 黄金窗口期，优先响应 |

## 九、信号强度量化（接续V4.0第九章）

### 9.1 从二值到五级

| 强度 | 条件(示例·A类) | 含义 | 视觉 |
|:--:|------|------|:--:|
| **0·无** | 无相关事件 | 无此信号 | ○ 灰 |
| **1·弱** | f3=1(1个未闭环) | 信号刚出现 | ◐ 浅色 |
| **2·中** | f3=2(2个未闭环) | 信号明确 | ◑ 标准色 |
| **3·强** | f3≥3 或 超SLA | 信号强烈 | ● 深色 |
| **4·极强** | f3≥5 或 含攻击 | 需要立即处理 | ⬤ 红色 |

### 9.2 五级映射到得分区间

| 强度 | 得分区间 | 六类通用映射 |
|:--:|:--:|------|
| 0·无 | 0 | 所有类别 |
| 1·弱 | 1-25 | 特征值×权重 < 25 |
| 2·中 | 26-50 | 特征值×权重 26-50 |
| 3·强 | 51-75 | 特征值×权重 51-75 |
| 4·极强 | 76-100 | 特征值×权重 > 75 |

## 十、时间维度颗粒度细化

### 10.1 事件新鲜度分级

| 时间 | 标记 | 含义 |
|------|:--:|------|
| ≤24h | 🔴 刚刚 | 最高优先级，可能就是正在发生的问题 |
| 1~3天 | 🟠 近日 | 新鲜，趁热跟进 |
| 4~7天 | 🟡 本周 | 仍活跃，正常跟进 |
| 8~14天 | 🟢 半月内 | 开始降温，评估是否需重新激活 |
| 15~30天 | 🔵 月度 | 趋于稳定 |
| >30天 | ⚪ 陈旧 | 仅作历史参考，自动衰减 |

### 10.2 状态迁移速度

| 迁移速度 | 条件 | 含义 |
|:--:|------|------|
| **快速恶化** | 7天内分类恶化≥2级(如C→E) | 高风险预警 |
| **缓慢恶化** | 30天内分类恶化1级 | 值得关注 |
| **稳定** | 30天内分类不变 | 正常 |
| **缓慢改善** | 30天内分类向好1级 | 正面 |
| **快速改善** | 7天内分类向好≥2级 | 趁热打铁 |

### 11.1 personalityType → 分类策略微调

| personalityType | 对分类的影响 |
|------|------|

| communicationPreference | 触达方式 |
|------|------|
