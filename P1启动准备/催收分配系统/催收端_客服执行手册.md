## 一、你每天只需要做四件事

```
① 打开个人池，从上往下点拨号（顺序系统已排好，不用挑）
② 通话结束，选感受分（1~5，标准见第二章）
③ 觉得能留的，拉进意向池（≤50户）
④ 打完收工
```

**不用你做**：不用自己排序、不用自己分人、不用记谁的标签——系统全部自动。

## 二、感受分锚定标准（必读，这是数据质量的生命线）

感受分不是凭感觉打，是对着标准打：

| 分 | 标准 | 锚定示例 |
|----|------|---------|
| **1** | 辱骂 / 威胁 / 明确拒缴施压 | "再打就报警""有本事你们来收" |
| **2** | 敷衍冷漠，拒绝沟通 | "再说吧"（带负面情绪，不等你说完就挂） |
| **3** | 中性——正常沟通，没答应也没拒绝 | "我知道了"（平静听完，不表态） |
| **4** | 态度较好，有沟通意愿 | 愿意听你解释，问了物业的情况，说过几天看看 |
| **5** | 明确答应付款 / 给出具体还款时间 | "这周内去交""下个月发工资就交" |

**三条纪律**：
1. **先听后打**——感受分依据是通话内容，不是你的个人印象
2. **给 4 分要慎重**——4 分是"行为正向"的门槛线（配合 AI 评分≥61 会进入正向跟单），只有"有沟通意愿"才能给
3. **拒接/未接不选感受分**——系统自动记录，你不需要操作
4. **感受分必选**——每通电话结束必须选完感受分才能拨下一个号；忘记选会标记待补录，别留空

## 三、你的列表顺序是怎么排的（界面排序说明）

你的个人池分**四段**，从上往下打：

```
档1 超大额（62户）→ 档2 大额（83户）→ 档3 中额（73户）→ 档4 小额（42户）
```

**注意**：档1 大约 2 周就打完了，之后系统会把配额自动下传给后面的档——所以你看到的"档1 段"会越来越短，更多是档3、档4 的户。这是正常的，不用疑惑。

每段内部，系统按**"回款可能性"**排的序，参考五个信号：

- AI 评价分（AI 听了通话内容后打的回款概率预测）
- 标签（B 困难型最靠前——有困难但有沟通意愿的人最容易还）
- 你的感受分（你上次说这人态度不错，他就前移）
- 新鲜度（新数据优先）
- 探索分（没打过的优先）

**所以看到"小金额排在大金额前面"不是系统坏了**——是因为系统判断这个人更可能还钱。你的任务就是按顺序打，别跳着打。

## 四、六类标签话术卡（遇到对应标签，用对应话术方向）

### A · 合理争议型（"漏水没修，修好我就交"）
- **方向**：缴费与争议分开
- **动作**：① 先认真听完，记下具体争议（哪栋哪户什么事）② 在系统里录入争议（管理员会每日汇总发物业群跟进）③ 说："您说的问题我登记了，会反馈给物业；这笔费用我们分开看，您看怎么安排？"
- **承诺时点**：如果业主说"修好了我就交"并给出时间——记下时间，系统会在到期前 3 天把这个户排到你列表前面
- **禁止**：不能因为业主有争议就跳过催缴——但也不能把缴费压在争议上威胁

### B · 现实困难型（"失业了，缓两个月"）
- **方向**：不施压，找分期
- **动作**：① 先表示理解 ② 问清困难的性质（失业？生病？变故？）③ 引导："能不能先交一部分？或者我们分几期？"
- **禁止**：不要说"那也要交""逾期会怎样怎样"

### C · 观望拖延型（"别人都没交"）
- **方向**：制度压力 + 共识教育
- **动作**：① 数据对照："您楼栋大部分业主已经交了" ② 守约共识："物业费是大家共同的保障，您家也用着电梯、保洁、保安" ③ 引导："您看这周方便处理吗？"
- **禁止**：不要评论其他业主、不要提滞纳金

### D · 惯性失约型（第三次说"这两天就交"）
- **方向**：锁定承诺
- **动作**：① 确认具体时间："您说这两天，是周四还是周五？" ② 记录承诺时间（系统自动记）③ 到期前系统会安排提醒
- **禁止**：不要在业主没给出时间时替他说时间

### E · 对抗失信型（拒接/对抗）
- **方向**：不刺激，短平快
- **动作**：① 一句话说明来电目的 ② 对方抗拒立即收尾："好的，打扰了" ③ 挂断后系统**本月不安排人工**（当月不再出现在你的列表；外呼机器人会按正常催收流程继续通知，下个月才可能再排到人工）
- **禁止**：不辩论、不施压、不威胁——对抗的业主你越压他越刚

### F · 历史遗留型
- 你的列表里**不会出现**（已自动移出）。如果发现空号/停机/已搬家，正常打完挂断即可，系统自动识别。

## 五、红线（一句话都不能说）

| 禁用语言类型 | 例子 |
|-------------|------|
| 滞纳金威胁 | "滞纳金自己承担""每天累积" |
| 权限威胁 | "影响门禁""影响停车" |
| 信用恐吓 | "影响征信""拉黑名单" |
| 后果施压 | "越拖越多""过期就来不及了" |

**治理不是催收**：你的工作是把焦点从"你欠了多少钱"转移到"你遇到了什么问题"。在催收系统里，你实际能做的三件事：① 按话术卡沟通（A 类记争议、B 类问困难、C 类讲共识）② 把业主诉求记录下来（争议反馈物业微信群）③ 选好感受分、拉好意向池。平台上的工单、服务记录那块由数治理方系统对接，不由你操作。

## 六、常见场景速查

| 场景 | 怎么做 |
|------|--------|
| 业主说"不是不交，是物业不作为" | 按 A 类处理：记录争议转物业 + 缴费分开谈 |
| 业主说"别人都没交" | 按 C 类处理：数据对照 + 共识教育 |
| 业主说"最近手头紧" | 按 B 类处理：了解困难 + 分期引导 |
| 业主挂断 | 选感受分 2，系统自动安排回流 |
| 业主骂人 | 不还嘴，冷静收尾，选感受分 1 |
| 业主明确答应交 | 选感受分 5，能拉意向池就拉 |
| 通话中业主提到上次机器人通知 | 顺势说："那是系统自动的通知，具体您有什么问题我帮您看" |
| 界面提示"上次外呼中业主提到没钱" | 这是待确认线索——主动问："上次通知里您提到资金紧张，现在情况怎么样？" |
