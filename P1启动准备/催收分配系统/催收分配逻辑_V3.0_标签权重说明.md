# 标签与权重说明 · 每周债权分配（V3.2）

> 版本：V3.2 ｜ 日期：2026-08-21
> 用途：每周债权分配时，六类标签如何决定债权去向、档内排序权重与催收策略。
> 模型：二维——金额分档定配额，档内六因子加性 score 定顺序。

---

## 一、标签在每周分配中的三个作用层次

```
层次1 · 去向分流（轮换前预处理）
   F → 历史遗留池（不占配额）    E → 搁置池（不占配额）
   A/B/C/D/无标签 → 正常通道（占配额）

层次2 · 标签分（档内 score 的因子之一，权重 20%）
   标签分 0-100，与 AI 评价分、感受分等因子加性合成 score

层次3 · 策略差异化（客服端呈现）
   每类标签对应不同的催收话术方向与动作建议
```

## 二、标签 × 去向 × 权重总表

| 标签 | 名称 | 每周分配去向 | 占配额 | 标签分（0-100） | 分配动作 | 催收策略 |
|------|------|-------------|--------|----------------|---------|---------|
| F | 历史遗留型 | 历史遗留池 | 否 | 不参与 | 移出，客服自行反馈物业微信群核实 | 人工审核解除 |
| E | 对抗失信型 | 搁置池（本月） | 否 | 20（仅回归参考） | 移出，跨月回主池 | 不刺激，跨月按 C 重评 |
| A | 合理争议型 | 正常通道 | 是 | **40** | 正常排队 | 缴费与争议分开：记录争议转物业 + 继续催缴 |
| B | 现实困难型 | 正常通道 | 是 | **100** | 正常排队 | 不施压，分期协商 |
| D | 惯性失约型 | 正常通道 | 是 | **72** | 正常排队 | 承诺机制，按正常催收阶段流程走（不另安排） |
| C | 观望拖延型 | 正常通道 | 是 | **60** | 正常排队 | 制度压力 + 共识教育 |
| 无标签 | 未触达 | 正常通道 | 是 | **60** + 探索分100 | 正常排队 | 首次触达重点了解 |

**标签分排序**：B(100) > D(72) > C(60) = 无标签(60) > A(40) > E(20)。F 不参与。

## 三、每类标签的分配画像

### F · 历史遗留型
- **去向**：历史遗留池，不占配额，催收列表不显示
- **标签分**：不参与 score 计算
- **每周动作**：轮换前移出；客服自行反馈到物业微信群，由物业核实
- **回归**：人工审核解除（唯一人工标签环节）→ 重新分类回主池

### E · 对抗失信型
- **去向**：搁置池（本月），不占配额
- **标签分**：20（仅用于搁置到期后回归排序的参考）
- **每周动作**：轮换前移出；每日 08:00 检查搁置到期
- **回归**：跨月 → 回主池，按 C 口径参与排序；重新接通后按新标签重评

### A · 合理争议型
- **去向**：正常通道，占配额，**继续催收**
- **标签分**：40（争议未解决，回款概率打折——排在同档同条件债权靠后位置）
- **每周动作**：正常排队分配；客服通话中记录争议（dispute_ref）转物业
- **核心**：缴费与争议分开——争议走物业线，缴费走催收线，互不停
- **权重逻辑**：40 分不是"放弃"，是"降速"。争议解决后标签重评，标签分自然回升

### B · 现实困难型
- **去向**：正常通道，占配额
- **标签分**：100（六类中最高——有沟通意愿 + 分期通道，回款概率最大）
- **每周动作**：正常排队；客服不施压，了解困难，引导分期
- **权重逻辑**：困难≠拒缴。B 类业主"想交但暂时交不出"，分期方案落地即可回款，是催收资源的最优去处

### D · 惯性失约型
- **去向**：正常通道，占配额
- **标签分**：72（承诺过但敏感度低，轻触达可收割）
- **每周动作**：正常排队；承诺机制（记录承诺时间，到期提醒）；按正常催收阶段流程走
- **权重逻辑**：D 类是"答应过没做到"，有还款意向证据但需要制度约束，标签分高于 C 低于 B

### C · 观望拖延型
- **去向**：正常通道，占配额
- **标签分**：60（基准值）
- **每周动作**：正常排队；制度压力话术（数据对照 + 守约共识教育）
- **权重逻辑**：C 是主战场——"搭便车"群体需要做功，但个体回款概率平庸，取基准分

### 无标签（未触达）
- **去向**：正常通道，占配额
- **标签分**：60（基准）+ **探索分 100**（未触达加分，随未接通次数衰减 100→50→25→0）
- **每周动作**：首次触达重点了解（原因/困难/争议排查）
- **权重逻辑**：探索分保证"没打过的先打"——首轮全覆盖目标由它实现；打过无响应的探索分衰减，自然让位

## 四、score 公式中标签的位置

$$score = \underbrace{0.30 \times AI评价分}_{\text{回款概率预测}} + \underbrace{0.20 \times 标签分}_{\text{静态画像}} + \underbrace{0.10 \times 感受分}_{\text{客服判断}} + \underbrace{0.15 \times 数据新鲜度分}_{\text{新鲜度}} + \underbrace{0.20 \times 探索分}_{\text{覆盖保护}} + \underbrace{0.05 \times 等待分}_{\text{回流防饿死}}$$

**标签是六大因子之一（20%），加性参与，不是乘性权重。**
- 档间：金额分档决定火力（档1-4 配额 62/83/73/42）
- 档内：score 决定顺序——标签分在档内有真实话语权，但不再与金额硬拼

### 计算示例（同档内）

| # | 债权 | 计算 | score |
|---|------|------|-------|
| 1 | B类 · AI=85 · 感受5 · 10天 · 未触达 | 25.5+20+10+12+20+0 | **87.5** |
| 2 | C类 · AI=40 · 感受2 · 10天 · 未触达 | 12+12+4+12+20+0 | **60.0** |
| 3 | C类 · 未接通回流 · 等待20天 · 打过1次 | 15+12+5+13.5+10+1.5 | **57.0** |
| 4 | 无标签 · 5天 · 未触达 | 15+12+5+15+20+0 | **67.0** |
| 5 | A类 · AI=60 · 感受3 · 60天 · 打过1次 | 18+8+6+4.2+10+0 | **46.2** |
| 6 | D类 · AI=70 · 感受4 · 15天 · 未触达 | 21+14.4+8+13.5+20+0 | **76.9** |

**观察**：
- 例1 vs 例2：AI 评价分拉开 27.5 分——"AI 认为会还钱的人"在档内显著前移
- 例4（无标签新户 67）> 例3（打过无响应 57）：探索分保证新户先打
- 例5（A 类 46.2）：争议户仍参与排队，但处于档内中低位——降速不放弃
- 标签分的影响：B(100) 与 A(40) 差 60 分 × 20% 权重 = 12 分差距，加上 AI 评分差异，实际排序差距可达 25 分以上

## 五、权重生效时机（每周轮换流程中的位置）

```
周一 8:30 / 周三 12:00 轮换
  ├── 步骤1 标签预处理：F/E 移出（去向分流，标签分不参与）
  ├── 步骤3-4 配额切分：金额四档（62/83/73/42）+ 新数据 40 + 正向 X
  ├── 步骤5 档内排序：六因子 score 计算（标签分/AI评价分在此生效）
  ├── 步骤6 蛇形轮流：score 降序队列轮转分人
  └── 步骤7 落库：客服界面按档序 + 档内 score 顺序显示
```

**轮换间隙**（通话事件）：AI 评价分/感受分/标签更新 → 该债权 score 重算 → 个人池内排序实时刷新（只动顺序，不换人）。

## 六、标签变化时的处理

| 场景 | 处理 |
|------|------|
| 拨打中发现 F（空号） | 立即移出个人池 → 历史遗留池，本轮配额不补 |
| 拨打中判 E（拒接3次） | 立即移出 → 搁置池，shelf_month = 当前月份 |
| C → B（说出困难） | 留在个人池，标签分 60→100，score 重算排序前移 |
| B → C（连续2次无困难词） | 标签分 100→60，排序后移 |
| A 争议解决 | 标签重评后标签分自然恢复，不额外操作 |
| 正向跟单户标签恶化（→E/F） | 立即退出正向跟单，转对应池 |

## 七、参数表（默认值）

| 参数 | 默认值 | 说明 |
|------|--------|------|
| 六因子权重 | AI评价30% / 标签20% / 感受10% / 时效15% / 探索20% / 等待5% | 可调 |
| 标签分映射 | B=100 / D=72 / C=60 / 无标签=60 / A=40 / E=20 | 可调 |
| 感受分映射 | 1-5 × 20 → 20~100 | 可调 |
| 数据新鲜度分映射 | ≤7天=100 / 8-14天=80 / 15-21天=60 / 22-28天=40 / 29-60天=28 / >60天=20 | 可调 |
| 探索分映射 | 本月未接通 0次=100 / 1次=50 / 2次=25 / ≥3次=0（每月1日清零） | 可调 |
| 等待分规则 | >14天每天+5，34天封顶100 | 可调 |
| 缺省分（未接通） | AI评价=50 / 感受=50 | 可调 |
| 金额分档切点 | top10% / 11-30% / 31-55% / bottom45% | 每月重标定 |
| 档配额比例 | 24% / 32% / 28% / 16% | 可调 |

---

*标签决定去向，六因子决定顺序，档配额决定节奏。*
