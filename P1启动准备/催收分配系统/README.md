## 模型一页纸（V3.2 定稿）

```
第一原则：回款为主，覆盖为基
池机制：周一指定项目集 → 周池（每周重建，call_count 跨周保留）
分档：金额四档 档1-4 = top10%/11-30%/31-55%/bottom45%，配额 62/83/73/42
排序：五键 (豁免标志, call_count, score, 金额DESC, debt_id)
  豁免：promise_due前3天 且 失信<3次；到期未回款→撤销+失信+1+call重置1
  call_count：本月人工沟通记录数（不含外呼）
score = 0.3×AI评价 + 0.2×标签 + 0.1×感受 + 0.15×数据新鲜度 + 0.2×探索 + 0.05×等待
  AI评价：五维度（态度/配合度/困难真实性/承诺可信度/争议严重度）各0-20合成
  标签分：B=100 D=72 C=60 无标签=60 A=40 E=20（F不参与）
  探索/等待：本月口径，每月1日清零
补位：档内新户不足 → 缺额下传（模拟验证 5 周 100% 覆盖）
配套：标签延迟生效、同业主绑定分配、参数月度锁定、感受分必选、一致性抽查
合规：外呼≤2/户/周、时段窗口、录音留存、话术四禁
治理：P0影子模式 → 六指标看板 → 退化检测(环比>20%) → 月度复核
```
