## 〇、本手册怎么用

《客服执行手册》是按**标签**组织的话术方向（A 类记争议、B 类问困难……），本手册是按**流程节点**组织的开场与应对。两份配合使用：

```
界面看到业主的流程节点 → 用本手册的开场白开口
业主回应 → 按执行手册的标签卡定对话方向
通话结束 → 收尾三件套（分类 / 感受分 / 意向池）
```

一句话：**节点话术管"你开口说什么"，标签卡管"业主说话后你往哪走"。**

### 节点总览

| 节点 | 阶段定位 | 此时业主可能已经收到过的通知 |
|------|---------|---------------------------|
| 引导 | ≤1月债权，AI 铺垫回电 | AI 电话："有一笔费用记录需要跟您核对"（不报金额） |
| 节点1 | 预分配·初次接触 | AI 电话："有一笔费用还未处理，有疑问请致电热线" |
| 节点2 | 第一次沟通·律师函预告 | AI 电话："如仍未处理，后续将发送律师函"（不给时间） |
| 节点3A | 律师函·发函前（仅周一~周三） | AI 电话："本周四短信发送，3日内处理可停止" |
| 节点3B | 律师函·已发送（周四起） | 律师函短信已发到业主手机 |
| 节点4 | 公示告知 | AI 电话："下一步将进入公开公示环节" |
| 节点5 | 信用报送前告知 | AI 电话："将报送信用平台，这是最后一次协商机会" |
| 节点6 | 上传平台·24小时窗口 | AI 电话："24小时内可协商，超时无法撤回" |
| 节点7 | 告知函寄送后 | 纸质告知函已寄出 |

节点由系统自动推进（每节点 AI 未接通重试 3 次后推进下一节点），你不需要操作，只需要**按界面显示的节点用对应的开场白**。

## 一、通用规范（所有节点都适用）

### 1.1 身份与称呼

- 开场统一：**"您好，〔姓名〕业主。我是受〔物业公司〕委托的〔公司名〕。"**
- 称呼"〔姓名〕业主"，不用先生/女士（系统无法判断性别）
- 业主问"你们是谁？"→ 如实回答："我们是受〔物业公司〕委托做费用核对和协调的第三方服务公司，不是物业内部人员。"

### 1.2 金额播报

| 节点 | 金额规则 |
|------|---------|
| 引导 / 节点1 / 节点2 | **不主动报金额**——先听原因，业主问起才如实回答 |
| 节点3A 起 | 可主动报金额，逐位读（"三千二百八十五元六角"），报前稍作停顿 |

金额是事实，不是筹码。报就报准，不虚报、不隐瞒。

### 1.3 红线（一句话都不能说）

| 禁用语言类型 | 例子 |
|-------------|------|
| 滞纳金威胁 | "滞纳金自己承担""每天累积" |
| 权限威胁 | "影响门禁""影响停车" |
| 信用恐吓 | "影响征信""拉黑名单""以后贷款买房都受影响" |
| 后果施压 | "越拖越多""过期就来不及了" |

**节点5/6 特别提醒**：只说流程事实——"按照流程，这笔记录将报送信用平台"，就到这里。报送之后有什么影响，是平台规则的事，**不归你说**。把"流程事实陈述"和"威胁性延伸"分清楚：前者可以，后者一句都不能说。

**治理不是催收**：你的工作是把焦点从"你欠了多少钱"转移到"你遇到了什么问题"。业主有争议记争议、有困难问困难、愿处理约时间——施压换不来回款，出口换得来。

### 1.4 收尾三件套（每通必做）

```
① 选分类（A-F 六类，系统必选）
② 选感受分（1-5，锚定标准见执行手册；拒接/未接不选）
③ 拉意向池（有希望回款的才拉，≤50 户；D/E 类不拉）
```

**承诺记录（两种类型，分开记）**：

| 业主说法 | 记录方式 | 系统行为 |
|---------|---------|---------|
| 给出具体时间（"下周二发工资就交"） | 记承诺时间 | 到期前 3 天该户自动排到你列表最前 |
| 口头答应、没时间（"好的我会交"） | 记在通话备注 | 无豁免，仅作为通话内容留存 |

## 二、节点话术卡

### 引导节点（≤1月债权 · AI 已铺垫）

**节点背景**：你打过未接 → 系统上 AI 引导外呼（不报金额、预告回电）→ 3 次后分回给你回拨，带标记"AI 已接通 / AI 未接通"。AI 已接通的户**当日或次日就要回拨**——新鲜度就是接通率。

**语气**：温和、服务感、零施压。

**开场白**：
> "您好，〔姓名〕业主。我是受〔物业公司〕委托的〔公司名〕。之前有电话联系过您，您名下有一笔费用记录需要跟您本人核对，现在方便说几句吗？"

| 业主回应 | 应对 |
|---------|------|
| "什么费用？" | "您在〔小区名〕的〔费用类别〕，系统里显示还没处理。这笔费用是什么情况，您这边清楚吗？" |
| "多少钱？"（主动问起） | 如实报金额，不多说。"是〔金额〕元。您是想确认下明细吗？" |
| "我不记得 / 不是我" | "没关系，可能是信息需要核对。我记录一下，反馈核实后再说。"（记备注，非本人→反馈管理者） |
| "你们到底是谁？" | 按 1.1 身份说明回答 |
| 挂断 / 拒接 | 不纠缠，记录（感受分 2），系统会自动安排后续 |

**注意**：本节点目标是**核对 + 铺垫**，不催收、不报金额（除非业主问）。

---

### 节点1（预分配通知 · 初次接触）

**节点背景**：AI 已通知"有一笔费用还未处理，有疑问请致电热线"。你的任务是**了解原因，不催收**。

**语气**：温和、耐心、服务型。

**开场白**：
> "您好，〔姓名〕业主。我是受〔物业公司〕委托的〔公司名〕。关于您在〔小区名〕的〔费用类别〕，系统里有一笔费用还没有处理，今天联系您，想了解一下是什么情况。"

| 业主回应 | 应对 |
|---------|------|
| "费用不对 / 面积算错 / 那段时间没住" | **A 类**：先听完，记下具体争议（哪栋哪户、什么事、涉及哪段时间）→ "您说的问题我登记了，会反馈给物业核实；这笔费用我们分开看，您看怎么安排？" |
| "最近确实困难 / 失业了 / 生病了" | **B 类**："理解。您说下现在是什么情况？……能不能先处理一部分？或者我们分几期？" |
| "别人交了吗？我再看看" | **C 类**："您楼栋大部分业主都已经处理了。物业费是大家共同的保障，您家也用着电梯、保洁、保安。您看这周方便处理吗？" |
| "我知道了"（平静听完不表态） | **C 类**："那我跟您确认个时间，您觉得哪天方便去处理？" |
| 挂断 / 拒接 | 不纠缠，记录 |

**注意**：节点1 的任务是**把原因问出来**。业主说了原因，就按对应标签方向走。

---

### 节点2（第一次沟通 · 律师函预告）

**节点背景**：AI 已预告"如费用仍未处理，后续将发送律师函"。预告只给方向、不给时间——**具体时间属于节点3A，你不要提前说**。

**语气**：温和、关切、点到为止。

**开场白**：
> "您好，〔姓名〕业主。我是受〔物业公司〕委托的〔公司名〕。之前系统联系过您，〔小区名〕的〔费用类别〕这笔费用目前还没有处理。按照流程，费用一直未处理的话，后续会向您发送律师函。今天想跟您确认一下：费用上有没有疑问，或者有没有什么困难？"

| 业主回应 | 应对 |
|---------|------|
| "为什么给我发律师函？" | "费用长时间未处理，发函是流程里的例行环节。发之前我们都会先跟您确认——费用上有什么疑问吗？" |
| "什么时候发？"（追问具体时间） | "按流程每周四统一通过短信发送，具体以短信通知为准。"（**不主动说**，问了才答；"3日内可停止"的窗口是节点3A的话，这里不给） |
| "我已经交了" | "好的，我记录一下，以物业那边的到账为准。已经处理了的话，后续流程就不会走。" |
| "那你们发吧" | 不接挑衅："好的。那再跟您确认一下：金额〔金额〕元，您没有疑问、暂时也不打算处理，我按现状记录。" |
| "你们别吓唬我" | "不是吓唬您，发函是流程里的一环。费用本身有什么问题，您说，能协调的我帮您协调。" |
| 争议 / 困难 / 观望 | 按 A / B / C 类方向走（同节点1） |

**注意**：本节点是"预告"，**律师函的具体发送时间、3日窗口一句话都不说**——那会造成口径混乱。业主追问，只答"每周四统一短信发送"这个流程事实。

---

### 节点3A（律师函 · 发函前 ⚠️ 仅周一~周三使用）

**节点背景**：AI 已预告"律师函将于**本周四**通过短信发送，**3日内**处理完毕将停止发送"。业主处于发函前最后窗口。

**语气**：正式、克制——通知事实 + 给出路。

**开场白**：
> "您好，〔姓名〕业主。我是受〔物业公司〕委托的〔公司名〕。系统之前通知过您，〔小区名〕的〔费用类别〕，律师函将于本周四通过短信发送到您的手机，金额共计〔金额〕元。如果在周四之前处理完毕，就不会发送。您看这笔费用怎么安排？"

| 业主回应 | 应对 |
|---------|------|
| "我周四前交" | 确认具体时间："您说周四前，是周三还是周四？" → 记承诺时间（系统到期前 3 天排最前）→ 感受分 5 → 拉意向池 |
| "没钱" | **B 类**："可以先处理一部分吗？周四之前能处理多少算多少，剩下的我们约个时间。" |
| "费用有问题" | **A 类**："您的问题我登记了，会反馈物业核实。发函是流程动作，缴费和争议我们分开处理——您看费用这边怎么安排？" |
| "吓唬谁呢 / 你们敢" | 不辩解、不施压："这是流程通知。费用方面您有疑问可以说，能解决的我们帮您解决。" |
| 沉默 / 犹豫 | "您看这样，周四之前能处理多少算多少，剩下的我们再约时间。您先说个能接受的时间。" |

**注意**：
- **时间对齐**：本卡**只在周一~周三用**。周四 00:00 起系统已切换，一律用节点3B 卡。
- 本节点接通户系统会**优先分配给高转化客服**——名单里出现时，认真按卡打。

---

### 节点3B（律师函 · 已发送 ⚠️ 周四起使用）

**节点背景**：律师函已于周四通过短信发出。你的任务是**确认送达 + 给出口**，不再说期限。

**语气**：平静、确定、陈述不施压。

**开场白**：
> "您好，〔姓名〕业主。我是受〔物业公司〕委托的〔公司名〕。关于〔小区名〕的〔费用类别〕，律师函已经通过短信发送到您的手机，您可以打开短信查看。金额共计〔金额〕元，目前还没有处理。您收到短信了吗？"

| 业主回应 | 应对 |
|---------|------|
| "没收到" | "您确认下手机尾号〔后四位〕的号码是不是在用？我记录一下，反馈核实发送情况。费用这边您可以先安排。" |
| "收到了，但我不认可" | **A 类**：记争议细节 → "您说的问题我登记了，会反馈物业核实。缴费和争议我们分开看，您看费用怎么安排？" |
| "收到又怎样" | 不接挑衅："律师函是流程通知。费用上您如果有异议，现在提出来，我帮您登记核实。" |
| "现在处理还来得及吗？" | 如实回答："费用处理了，流程就到此为止。您看什么时候方便去办？"（不承诺"停止发函"——已发送的事实不变，但后续节点不会推进） |

**注意**：本卡**周四起使用**（含周五）。不再说"3日内可停止"——承诺窗口已过，说了就是失信。

---

### 节点4（公示告知）

**节点背景**：AI 已通知"下一步将进入公开公示环节"。你的任务是告知公示 + **必须给异议出口**。

**语气**：郑重、警示但不激动。

**开场白**：
> "您好，〔姓名〕业主。我是受〔物业公司〕委托的〔公司名〕。关于〔小区名〕的〔费用类别〕，金额共计〔金额〕元，目前仍未处理。按照流程，下一步这笔记录将进入公开公示环节。在公示启动前，您如果对费用有异议，现在提出来，我帮您登记。"

| 业主回应 | 应对 |
|---------|------|
| 提出异议 | **A 类**：完整记录（哪栋哪户、什么事、时间）→ "我登记了，会反馈物业核实。公示前提出异议，处理余地最大。" |
| "凭什么公示我？" | "公示是费用催收流程的常规环节，不是针对您个人。您对费用本身有异议的话，现在提出，我们核实。" |
| "公示就公示" | 不接挑衅："好的。那再跟您确认一下：金额〔金额〕元，您没有异议、暂时也不打算处理，我按现状记录。" |
| 犹豫 | 给出口："公示启动前处理掉，这笔记录就不会进入公示。您看哪天方便？" |

**注意**：异议出口是本节点的核心动作——**听异议比催缴费更重要**。业主提出异议就记全，别急着绕回催缴。

---

### 节点5（信用报送前告知 · 最后协商机会）

**节点背景**：AI 已通知"将按照流程报送信用平台，报送前是最后一次协商机会"。本节点接通户**直接分配王超勇/杜森斌**处理。

**语气**：严肃、郑重、克制。

**开场白**：
> "您好，〔姓名〕业主。我是受〔物业公司〕委托的〔公司名〕。关于〔小区名〕的〔费用类别〕，金额共计〔金额〕元。按照流程，这笔记录将报送信用平台。在正式报送前，这是最后一次协商机会，您看这笔费用怎么处理？"

| 业主回应 | 应对 |
|---------|------|
| "我不想被报送" | 给路："报送前还可以协商。您可以先处理一部分，或者我们约个具体时间，我在系统里记录。" |
| "随便你们 / 你们看着办" | 不接挑衅："那我跟您确认最后一遍：金额〔金额〕元，您没有异议、也暂时不打算处理，对吗？我按现状记录。" |
| "为什么针对我？" | "流程对所有未处理费用都是一样的，不是针对您个人。费用本身有疑问，您现在说，我帮您登记。" |
| 骂人 / 威胁（"再打报警"） | 冷静收尾："好的，打扰了。" → 感受分 1 → 记录（系统本月不安排人工，外呼照流程走） |
| 松口要谈 | 按承诺规则记录：有具体时间记时间，口头答应记备注 |

**注意**：报送是流程事实，可以陈述；**报送的后果（征信影响等）一个字都不能延伸**——那是平台规则的事，不是你施压的筹码。

---

### 节点6（上传平台 · 24小时窗口）

**节点背景**：AI 已通知"已进入报送流程最后阶段，24小时内可协商，超时已报送的记录无法撤回"。本节点接通户**直接分配王超勇/杜森斌**处理。

**语气**：严肃、冷静、紧急但不施压。

**开场白**：
> "您好，〔姓名〕业主。我是受〔物业公司〕委托的〔公司名〕。关于您在〔小区名〕的〔费用类别〕，目前已进入报送流程的最后阶段。在24小时内处理或协商，还来得及；超过这个时间，已报送的记录将无法撤回。您看现在怎么处理？"

| 业主回应 | 应对 |
|---------|------|
| "24小时来不及" | 给最小动作："这是流程时限。您看能处理多少是多少，剩下的我帮您登记个协商记录。" |
| "我不在乎" | 确认现状："那我跟您确认最后一遍：金额〔金额〕元，您不打算处理，我按现状记录。之后流程会正常走完。" |
| 骂人 / 威胁 | 同节点5：冷静收尾，感受分 1，记录 |
| 松口要谈 | 时间窗内能成交就成交——确认金额、确认动作、记录 |

**注意**：24小时是**流程事实**，说清即可，不重复施压、不催促渲染。

---

### 节点7（告知函寄送后 · 人工待处理名单）

**节点背景**：AI 流程已走完（7 节点全未接通），平台已寄送纸质告知函，该户标记"长期失联"，进入人工待处理名单。这是**最后的人工触达**。

**语气**：平静、陈述、礼貌请求。

**开场白**：
> "您好，〔姓名〕业主。我是受〔物业公司〕委托的〔公司名〕。关于您在〔小区名〕的〔费用类别〕，金额共计〔金额〕元，目前仍未处理。公司已向您寄送书面告知函，请您留意查收，尽快处理。如有疑问，请致电〔服务热线〕。"

| 业主回应 | 应对 |
|---------|------|
| 空号 / 停机 / 已搬家 | 记录（F 类线索），反馈管理者核实信息 |
| 接通且平静 | "这是告知函的提醒电话。费用您现在处理，流程就到此为止。" |
| "太晚了，早干什么去了" | 不辩解："之前系统有多次电话和短信通知，可能您没留意。费用您现在处理，流程就停止。" |
| 提出争议 / 困难 | 照常登记（A/B 类），反馈物业微信群，缴费分开看 |

**注意**：本节点户大概率号码已失效。**发现空号/停机/搬家，如实记录反馈**，比空打更有价值。

## 三、跨节点场景速查

| 场景 | 怎么做 |
|------|--------|
| 业主说"已经交了 / 刚转账" | 记录"已缴待核实"，以物业到账为准。不纠缠、不质疑。 |
| 非本人 / 号码换人 | 礼貌收尾，记录反馈管理者核实 |
| 业主说"在开会 / 忙" | 约回访时间并记录："那您看什么时间方便，我再打过来。" |
| 业主骂人 / "再打报警" | 不还嘴："好的，打扰了。" → 感受分 1 → 记录（E 类本月不安排人工） |
| 业主问"为什么老打电话" | "系统里有多次电话和短信通知记录。今天联系您是想把费用这件事处理掉，处理完就不会再有电话了。" |
| 业主提上次机器人通知 | "那是系统自动的通知。具体您有什么问题，我帮您看。" |
| 界面提示"上次外呼中业主提到没钱" | 主动确认："上次通知里您提到资金紧张，现在情况怎么样？" |
