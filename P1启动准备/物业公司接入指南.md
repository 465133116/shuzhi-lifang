# 物业公司接入指南（5分钟上手）

## 你们需要做什么

### 第一步：提供数据（1天）
把这三样东西给我们：
1. **业主名单** → Excel，含姓名/手机号/房号
2. **物业合同** → PDF，用于定义服务时限
3. **欠费数据** → 哪些业主欠费、欠多少、欠多久

### 第二步：张贴二维码（1小时）
我们在每栋楼电梯间贴一个二维码。
业主扫码就能报修、投诉、提建议。

### 第三步：安排一个人看后台（每天10分钟）
工单来了→系统自动接单→你们内部派人处理→处理完上传照片→等业主评价。
超时会自动提醒，不用你们盯着。

## 系统帮你们做什么

| 之前 | 之后 |
|------|------|
| 业主打电话说"电梯坏了"→没记录 | 业主扫码报修→有照片+时间戳 |
| 修完了业主说"没修好"→没证据 | 修前一张修后一张→有据可查 |
| 总部问"你们干了什么"→说不出 | 看板数据→工单数/处理率/满意度 |
| 业主不交费→只能催 | 信用分公开→该交的人自己会交 |
