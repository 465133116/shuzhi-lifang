# 客服操作手册（P1）

## 你的工作流程

```
AI外呼结果 → 有争议的业主 → 你打电话 → 创建草稿 → 推送确认 → 跟踪状态 → 回访
```

## 每天做什么

### 上午 (9:00-12:00)
1. 打开客服端，查看待跟进面板
2. 按"差评需回访"→"待验收"→"问题未解决"顺序处理
3. 每个电话控制在3分钟内

### 下午 (14:00-18:00)
1. 查看AI外呼结果，筛选"有争议"的业主
2. 逐一外呼，创建草稿工单
3. 记录通话结果和备注

## 打电话怎么说

| 场景 | 话术 |
|------|------|
| 开场 | "您好，我是数治理方客服，受物业委托做服务回访" |
| 业主投诉 | "您说的情况我记下了，稍后推送到您手机上确认" |
| 业主问费用 | "我这边是服务回访，不涉及费用" |
| 引导确认 | "稍后您会收到一条短信，点开确认就行" |

## 禁止做的事

- 不提"催缴""欠费""物业费"
- 不承诺任何处理结果
- 不与业主争论
- 不透露其他业主信息
