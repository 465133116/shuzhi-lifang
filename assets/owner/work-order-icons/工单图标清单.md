# 业主端图标清单

本目录包含业主端工单、公告、通知、年度计划、社区动态等涉及的图标，便于在其他项目中复用。

## 使用方式

### 在 HTML 中
```html
<link href="assets/owner/fontawesome/css/all.min.css" rel="stylesheet">
<i class="fa-solid fa-screwdriver-wrench"></i>
```

### 复制整个图标资源包到其他项目
复制以下目录即可：
- `fontawesome/` — 字体与样式
- `work-order-icons/` — 本清单与预览页
